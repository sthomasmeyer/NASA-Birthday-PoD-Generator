# NASA Date-specific PoD Generator

This React.js application generates every NASA Astronomy Picture of the Day (APOD) published on a user-selected calendar date (from June 16, 1995 to the present). It queries NASA's official `science.nasa.gov` REST API (`wp-json/wp/v2/apod-basic`) using native `fetch()` with zero API key setup required.

### Local Installation Guide

1. Clone the repository.
   - [GitHub's Guide to the Git Clone Command](https://github.com/git-guides/git-clone)
2. Navigate into the project directory.
3. Install the project dependencies using `npm install`.
4. Run the local development server with `npm run dev`.
